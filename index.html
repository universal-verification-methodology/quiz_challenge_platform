Digital Foundations Quest

Topic blocks are shuffled. Inside each block you climb easy → medium → hard. Clear each difficulty with one correct answer (up to 10 tries, no repeats). Length is not fixed — best case is short; tough runs take longer. Analysis comes only at the end. Each question has a time limit (easy 30s · medium 45s · hard 60s) so you answer from knowledge, not a paste into AI.

How length works

  • Best case: 3 modules × 3 difficulties × 1 correct = 9 questions.
  • Worst case: 3 × 3 × 10 attempts = 90 questions (then that level gives up).
  • Bank size: 30 questions per difficulty (3× the max attempts) so items are not reused in a level.
  • No mid-quiz answer key — the report explains right/wrong and timing after you finish.
  • Pick an answer; if it stays selected for about a second, the quest moves on automatically.
  • Time limit: easy 30s · medium 45s · hard 60s. Timeout counts as wrong and advances.
  • Test mode: 2 modules × 2 difficulties (easy/medium), max 3 tries per level — best 4 / worst 12.

Module names stay hidden during the quest; the report maps results back to learn_digital for learning feedback.
